# 知识摄取版本绑定与租约升级

2026-10-30。适用 V55/V56；两份迁移均为新增版本，不修改已发布 SQL。

部署前停止全部旧版摄取 Worker，等待正在执行的任务退出，再执行迁移和启动新版。旧版程序不认识 fencing 条件，不能与新版并行滚动执行摄取；仅靠新列不能约束旧版无条件 UPDATE。

V55 禁止已存在文档身份、指纹和正文覆盖；状态停用仍允许。服务端对首个 BOM 和 CRLF/CR 换行做规范化，保存 UTF-8 SHA-256。重复提交相同版本不重排摄取；内容或既存指纹不一致返回冲突。已有历史指纹须审查，不能直接改写历史 Citation 对应的数据。

V56 将任务从内容哈希关联改为文档版本外键，Attempt 是单调执行代次，claim_owner 唯一标识领取者。迁移只接受每个旧任务恰好映射一份文档的情况；缺失或歧义会显式中止。操作者须根据原始上传和任务历史核验数据并决定归属，备份后另行审议修复，禁止任取 MAX(version) 自动配对。旧 RUNNING 任务会增加代次后重新排队。

新版只有当前 owner/attempt 且租约未过期可续租或写终态。激活索引和成功回写在一个事务内锁定任务；过期或被接管的任务不能激活候选索引。候选索引构建可先完成，激活失败留下的候选应通过审计和后续保留策略清理，不能当作 ACTIVE 返回。

执行验证：Windows 使用 `mvnw.cmd verify`，Linux 使用 `bash ./mvnw verify`。必须在 Docker 可用环境运行 `KnowledgeDocumentImmutabilityIntegrationTest`，检查重复提交、篡改拒绝、租约接管和迟到完成。Docker 不可用导致 skipped 不算数据库验收通过。回滚应用前必须停摄取并确认数据库写入契约；不删除新迁移或移除不可变约束来迁就旧版程序。

也可通过 WORKFLOW_TEST_DATABASE_URL/USER/PASSWORD 显式配置**专用隔离测试数据库**执行该套件；测试会建立合成文档及临时升级测试数据库，账户需具备 CREATEDB，禁止指向业务数据库。2026-10-30 已在本机新建临时 PostgreSQL 18.1 集群完成真实迁移、拒绝歧义升级、租约接管与激活回滚测试。默认 CI 仍使用 Testcontainers；容器场景不能由本机结果替代。
