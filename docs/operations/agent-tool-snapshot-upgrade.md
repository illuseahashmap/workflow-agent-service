# Agent 工具元数据快照升级

2026-10-30，适用新增 V57。先按知识摄取升级手册完成 V55/V56，并停旧写入进程后执行迁移。

AgentVersion 发布会在同一事务中冻结工具名称、Schema、只读属性、能力、风险和副作用信息。新快照 provenance 为 PUBLICATION；已经发布的快照不能 UPDATE/DELETE。工具权限、启用状态以及只读限制仍实时检查，撤权不会因历史快照而失效。

旧版本没有保存最初发布时的工具元数据，无法从最新目录重建历史事实。V57 仅将升级时已经可观察的行为保存为 UPGRADE_BASELINE，避免今后随目录变化继续漂移；审计时不得将它当作原始历史发布快照。旧运行中的完整工具/模型上下文仍以既有 Checkpoint 和执行账本为准。需要更改工具契约时发布新 AgentVersion，并使用新版本回归。

若注册且已授权的工具缺少快照，运行明确报告 AGENT_TOOL_SNAPSHOT_MISSING；应核对发布数据、迁移与审核记录后发布新版本，禁止运行时自动发现或用最新目录补齐。部署后验证目录 Schema/描述变化不影响已发布版本，撤权后工具不可见，快照跨租户读取为空且跨租户关联被数据库拒绝。

所有模型、Embedding 和 MCP 传输已共用连接 DNS 地址策略；私有服务审批、生产网关和代理边界仍需验收，出站安全治理整体尚不能标记全部完成。生产不应开启开发环境的全局私网放行来替代私有服务授权。
