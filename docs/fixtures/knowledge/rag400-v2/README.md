# RAG400 v2：金标复核与检索对照

保留 v1 原始题库、承诺哈希与旧成绩；本目录是新的评测输入版本。仍为 400 题/200 组、30 份相同正文快照，DEV 200 / CALIBRATION 80 / 原保留集 120。不是独立标注或未曝光盲测。

此次完成全部 400 题的结构/引用/哈希/分组检查，以及 60 道缺证题、已发现的金标过度要求、冲突前提的重点语义复核；不声称逐条完成 400 道的独立人工裁决。生成过程见 scripts/rag400/curate-v2.py，逐项依据、前后哈希和范围见 gold-review.json。

- 两道已确认过度要求的 DEV 金标仅保留本问必要事实：停车口头转让不再强制回答换车登记；取消费用不再强制回答释放场地。
- 29 道缺证边界问题允许有依据的否定解释 ANSWER 或明确缺证的 ABSTAIN；语义评分仍必须满足 expectedAnswer/factsMissing，不能批准未核实业务结果。要求具体金额/余额/天数的题仍必须拒绝编造。
- 原保留题统一去掉评测指令前缀、与真实固定授权范围对齐；冲突题补明互斥前提。共 122 道 case 对象发生变化，29 条允许动作规则在旁路评分规则中记录。场景分类和分组不变。
- 原始作者自审日志随集保留为历史；本轮 gold-review.json 才是新增复核记录，independentReview=false。

只有 corpus 可摄取；queries 供检索/扩展/回答，cases、dependencies、gold-review 只供评分。四种检索共享本版本和最终 K=10，不能将 v2 成绩与旧 v1 的 68.5% 当作同条件提升。

执行与回传见 [远端说明](../../../operations/remote-rag-evaluation.md)。
