# 普通办公采购审批规则

采购政策摘编 · 测试版 1。取自 PROC-POL-01 草稿，仅供隔离环境评测，未批准用于真实采购。

## 第一条 金额口径

已确认为普通办公采购的，以同一业务需求的人民币含税总对价分档。不可选择的配送、安装费用计入总额；已付定金不从总额中扣除。金额为零、负数或必要费用未知时，先补资料，不得默认进入低档。

## 第二条 审批矩阵

| 档位 | 审批金额 A（人民币元，含税） | 审批与复核 |
| --- | --- | --- |
| 低档 | 0 < A ≤ 2,000 | 直属负责人审批。 |
| 中档 | 2,000 < A ≤ 20,000 | 直属负责人和部门负责人共同审批。 |
| 高档 | A > 20,000 | 直属负责人和部门负责人审批，财务中心复核预算；必要时提交采购委员会。 |

## 第三条 委员会与下单门禁

高档并不一律提交采购委员会。按本测试草案，拟选供应商未完成准入属于提交条件；准入状态未知时须核验，不能推断已满足或已豁免。委员会同意不代替供应商准入或预算落实。

政策只说明应走的审批路径。没有该采购单的实时预算、审批、报价有效期、准入和签署权限记录，不能断言已经获批或可以下单。
