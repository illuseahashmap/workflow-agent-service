# 原生表范围目录：V63 等价性能复测

范围：只优化关键词检索的表头候选查找，不增加 K、不改原件、问题、评分器及路由。V62 对每个候选表头做范围词数组匹配；V63 在写入/迁移时建立范围词到同租户、来源、索引和表头的映射。查到表头后仍经原 eligible 可见性边界，再按原规则取最长匹配及并列候选。报价或金额不参与表选择。

- 逐条比较 JSON 内容：样品制度 16 个质量格（含两档规模）与 V62 的顺序、缺失组、禁用命中均相同；设备维护三格式的 180 个对照/候选格也相同。样品制度仍为 6/8，S05 比较双方漏证、S06 同义范围漏召不是这次优化要解决的问题。
- 写入代价：扩容快照 386 个目录表头对应 8,094 条词项，49 个不同词；整个测试数据库该表连同索引占 3,784,704 字节（含小快照）。这是重复标题较多的合成语料；上线前应按实际词项数、维护窗口、写入与 WAL 容量估算。
- 已检验：两个租户各有已退休和活跃 V62 快照，升级后映射集合双向比对无差异。冻结旧版本仍可取证；错误租户、停用来源取不到，修改回滚不遗留部分映射，非超级用户读新表受租户 RLS 限制。V62 已有的范围数据无需重新发布。参见[升级注意事项](../../../../../operations/knowledge-source-snapshot-upgrade.md)。
