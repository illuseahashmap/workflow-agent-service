# 样品流转费用核签规程（合成评测原件）

## 样品冷链寄送

冷链寄送按一次交接单的含税承运总价核签。不可拆分的干冰附加费计入；温控台账不是承运费用。

| 线路 | 承运金额 Y（人民币元） | 核签责任 |
| --- | --- | --- |
| 常规线路 | 0 < Y ≤ 3,600 | 物流协调员签收报价。 |
| 专项线路 | Y > 3,600 | 生物安全主管复核报价；必要时提交质量例会。 |

专项线路仅在温度记录出现断点时提交质量例会。无轨迹数据时先调取温控记录，不能认定已经断链。

## 样品常温寄送

| 包装类别 | 寄送金额 Y（人民币元） | 核签责任 |
| --- | --- | --- |
| 周转箱 | 0 < Y ≤ 4,500 | 库管员核签。 |
| 防震箱 | 3,000 < Y ≤ 7,500 | 包装工程师核签。 |

两种包装的核签区间有交集。包装类别缺失时应补录装箱单，不得按运价猜包装。

## 样品库内移交

库内移交不经承运商。保管员按样品编号登记移交，不走寄送报价核签。
