# 样品运输：揭盲前的实验约定

目的：检验 V62 关键词适用范围检索能否迁移到新业务。原件为合成 Markdown，不是行业制度。未修改生产算法；同一研发者出题，不冒充外部盲审。独立于采购和设备维护；运行后转回归，不在此数据上宣称泛化。

- 固定同租户单来源、冻结快照、原始问句、Top5。金标按 policy.md 的物理行；requiredEvidenceGroups 组内 OR、组间 AND。forbiddenEvidence 是不可作依据的具体行；所有干扰文档都是非目标。分开报告取全、含干扰、两者兼顾；未标注行不自动算正确。expectedDisposition 是预期，不是模型结果。
- 小库只存原件；扩容档额外摄入 32 份可定位原件，每份 12 张同单位、重叠金额的异业务表。扰动检索内容，不向检索器传目标文档 ID、行号、答案或期望状态。两个快照均由原生摄取和激活生成。
- 每档 1 与 4 个同时工作的数据库连接，连接提前建立，每工作线程预热全部题；每格共 64 次实测，各题 8 次。仅计 search 调用；同步起跑、热查询、nearest-rank P95。不计入摄取、客户端建连、模型或工作流。记录每题排序、原始微秒与场景摘要；不设置未经批准的延迟门槛。扩容量级是固定试验点，不代表生产容量。
- 检索缺证不是 Agent 拒答。不得扩大 K 或修改金标使报告通过；保留失败及需要补证的场景。
