**时延如何解释。** 正式表格在每档摄取后对参与可见性查询的四张表采集统计信息；耗时不含预热、建连、解析及 EXPLAIN。对照诊断中，只更新块表统计信息时，1,582 块单路 / 四路分别测得 532.193 / 1,869.587 ms。不能把它们当作当前正常 P95，也不能推断生产应在每次查询或摄取中执行 ANALYZE。新库或批量重建后应核查统计信息新鲜度。正常统计下扩容仍有明显成本：独立会话的 EXPLAIN 中 S06/S07 都在范围目录阶段出现 knowledge_chunk 顺序扫描。先验证分离表头目录候选的查询计划，再考虑重排；更大、更多样语料和真实并发负载另验。
