# 设备维护费用授权细则

日常检修按单次停机工单的含税合计分档，强制校准费计入。强制费用未确认时，先补齐报价，不得按零元处理。

## 日常检修工单

| 检修级别 | 检修金额 M（人民币元） | 处理要求 |
| --- | --- | --- |
| 现场件 | 0 < M ≤ 4,800 | 班组长签认。 |
| 计划件 | 4,800 < M ≤ 15,000 | 维修主管复核。 |
| 重大件 | M > 15,000 | 厂长签批；必要时组织安全会审。 |

重大件仅在涉及联锁旁路时组织安全会审。旁路状态未知应先查作业票，不得认定已经触发或已经豁免。

## 年度改造预算

| 预算类别 | 改造金额 M（人民币万元） | 处理要求 |
| --- | --- | --- |
| 常规项目 | 0 < M ≤ 1.5 | 投资经理核定。 |
| 重点项目 | M > 1.5 | 投资小组审议。 |

改造额度仅适用于年度立项，不是日常检修工单的签批依据。

## 临时外协定额

| 外协类别 | 外协金额 M（人民币元） | 处理要求 |
| --- | --- | --- |
| 机械校验 | 0 < M ≤ 6,500 | 交机械工程师核对。 |
| 仪表校验 | 6,000 < M ≤ 12,000 | 交仪表工程师核对。 |

临时外协按设备专业选行。金额范围有交集且专业未登记时，退回补录专业，不得默认采用第一行。
