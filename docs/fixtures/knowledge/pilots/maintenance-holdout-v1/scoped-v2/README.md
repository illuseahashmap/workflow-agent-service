### 实现及上线边界

1. 索引构建从表题、工作表名建立业务名称目录，引用位置绑定当前文档与索引。检索先按业务名称筛表，不以金额或单位选择业务。共享短名让位于包含它的明确长名；互不包含的两个业务名都保留，即使一个字数更多。
2. 只在该范围内匹配确定的人民币点值。单一明确原行可以带上表头和限定条款；类别不明时不把其中任一行解释成决定。两表同名或共享范围也不靠单位消歧。Excel 双表压力测试覆盖“只说采购”“两种业务皆可能”“明确普通办公采购”；九道采购开发题的金标及 K 不变。
3. V62 只添可空侧写列和索引，不改历史原件或已发布索引。上线须重建候选索引、验证、激活并发布绑定该索引的 Profile。未经识别的标题/同义词不享受可靠范围推断；冲突多于 K 时不能据部分证据下结论。关键词路径以外的融合、模型拒答以及 PDF 均未在此验收。
