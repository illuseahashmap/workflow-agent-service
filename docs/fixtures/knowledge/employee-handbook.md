# 星河科技员工工作手册

版本：2026.09

生效范围：星河科技及其全资子公司正式员工、试用期员工和长期实习生。外包人员、短期访客和合作方人员应遵守合同中约定的安全与保密条款，但不适用本手册中的员工福利政策。

## 一、组织与汇报关系

星河科技的组织分为产品中心、技术中心、客户成功中心、财务中心和人力资源中心。员工的直属负责人负责日常工作安排、目标确认和试用期辅导；跨部门项目由项目负责人协调，但项目负责人不能替代员工的正式直属负责人进行转正、调薪或劳动关系相关审批。

技术中心下设平台工程部、应用研发部、质量保障部和信息安全部。平台工程部负责公共工作流、Agent 平台和基础设施能力；应用研发部负责面向客户的业务系统；质量保障部负责发布质量、自动化测试和缺陷管理；信息安全部负责账号、密钥、数据访问和安全事件响应。

员工需要变更直属负责人、所属部门或工作地点时，应先由当前直属负责人发起变更申请，再由目标部门负责人确认。组织变更在 HR 系统生效后，新的负责人才能处理员工后续的审批任务。

## 二、工作时间与请假

标准工作时间为周一至周五 09:00—18:00，午休时间为 12:00—13:30。弹性工作必须满足团队值班安排和客户支持要求，不得因为弹性安排导致会议、值守或紧急响应无人负责。

年假申请应至少提前三个工作日提交；连续休假超过五个工作日时，应至少提前十个工作日提交。病假需要在当日上班前通知直属负责人，并按公司要求补充医疗证明。紧急情况下可以先通过即时通讯工具报备，返岗后再补录系统申请。

请假审批顺序通常为：员工提交申请 → 直属负责人审批 → 部门负责人审批（适用时）→ 人力资源备案。直属负责人超过一个工作日未处理时，员工可以联系部门负责人或 HR 服务台进行催办，但不得重复创建多条相同申请。

## 三、费用报销政策

员工因公产生的交通、住宿、客户接待和办公采购费用，应在费用发生后 30 个自然日内提交报销。报销单必须关联真实的业务事项，并上传合规发票、支付凭证和必要的审批记录。

单笔金额不超过 2,000 元的普通办公采购，由直属负责人审批；金额超过 2,000 元但不超过 20,000 元的采购，需要直属负责人和部门负责人共同审批；超过 20,000 元的采购，还需要财务中心复核预算，必要时由采购委员会审批。

差旅住宿标准按城市等级执行：一线城市普通员工每晚不超过 500 元，部门负责人每晚不超过 700 元；其他城市普通员工每晚不超过 350 元，部门负责人每晚不超过 500 元。因客户现场、重大项目或交通中断确需超标准住宿时，应在预订前取得书面批准，并在报销单中说明原因。

客户接待费用必须填写接待对象、人数、事由和业务关联。不得使用报销费用购买礼品、储值卡、虚拟货币或其他无法核验用途的物品。发票抬头、金额和日期与实际消费不一致时，财务中心可以退回报销单要求补充材料。

## 四、信息安全与数据使用

公司账号必须使用个人账号登录，不得共享密码、验证码、访问令牌或 API 密钥。生产环境密钥只能保存在批准的密钥管理系统中，禁止写入代码仓库、工单正文、即时通讯群或公开文档。

员工处理客户数据时，应遵循最小权限原则，只访问完成工作所必需的数据。导出客户数据前，必须确认导出范围、保存位置、保留期限和接收人员。包含身份证号、手机号、银行卡号、访问令牌或其他敏感信息的文件，不得通过个人邮箱或未经批准的网盘传输。

发现账号异常登录、密钥泄露、误发客户数据或生产数据异常时，应立即停止继续操作，并在 30 分钟内联系信息安全部。安全事件报告至少应包含发生时间、涉及系统、已执行的止损措施和可能影响范围，不应为了等待完整结论而延迟报告。

## 五、软件发布与变更

生产发布必须关联需求、代码变更、测试结果和回滚方案。普通工作日的发布需要在发布窗口内执行；紧急修复可以走紧急变更流程，但仍必须记录风险、审批人和验证结果。

数据库迁移脚本一旦在共享环境执行，不得直接修改原文件。后续结构修复必须新增版本化迁移，并在发布说明中记录兼容性、回滚限制和已执行环境。涉及租户隔离、权限、认证、外部工具和客户数据的变更，必须增加跨租户负面测试或等价验证。

Agent 或 MCP 工具接入时，默认只允许只读操作。工具的名称、输入 Schema、输出限制、超时、重试和授权范围必须在发布前冻结。模型不能直接获得租户凭证，也不能自行扩大知识范围或调用未绑定的工具。

## 六、常见审批场景

### 6.1 采购申请

采购申请至少包含申请人、部门、采购项目、预算金额、期望到货日期和用途说明。系统根据金额区间选择审批路径：小额采购进入直属负责人审批，中额采购增加部门负责人，大额采购进入财务和采购委员会复核。

### 6.2 访问权限申请

访问权限申请必须说明目标系统、权限级别、使用期限和业务依据。临时权限最长有效期为 30 天，到期后自动失效；长期权限每 90 天由系统发起复核。员工转岗或离职时，信息安全部应根据 HR 状态变更及时回收权限。

### 6.3 费用报销

报销申请若缺少发票、业务标识或审批依据，应退回补充，不应直接标记为已通过。金额校验通过并不代表业务审核通过，财务人员仍需核对费用真实性、预算归属和重复报销风险。

## 七、联系方式与升级路径

HR 相关问题联系 HR 服务台；报销和预算问题联系财务中心；账号、密钥和数据安全问题联系信息安全部；发布、工作流和 Agent 平台问题联系平台工程部。

无法确定归属时，先在工单中选择“平台服务台”，并提供业务标识、流程实例 ID、发生时间和 Trace ID。不要在工单中粘贴密码、完整访问令牌或客户敏感数据。服务台会根据问题类型转交给对应团队，并保留原始工单的审计记录。
