# P0 生产基线收口需求

变更 ID：P0-20260826

## 目标

收口当前短期计划中的 P0：让基础设施集成测试具备明确门禁，并让流程状态变化能够被授权运维按租户和关联标识查询。

## 范围

- 保留并验证现有 PostgreSQL、Redis、Flyway、RLS、HTTP 安全 Testcontainers 套件及 CI 缺失/跳过检查。
- 增加流程操作审计的只读应用端口、分页查询 API、租户隔离和 OpenAPI 契约。
- 验证 Prometheus 暴露和现有 Agent 运行指标。

## 非目标

- 不引入独立审计数据库或消息平台。
- 不改变既有流程状态机、审计写入语义和安全认证方式。
- 不在本机绕过 Docker 限制伪造集成测试通过。

## 验收标准

- AC-P0-01：CI 运行必需集成测试时，任何套件缺失或跳过都失败。
- AC-P0-02：具有审计读取权限的主体只能查询当前租户的流程操作审计；平台管理员按既有 RLS 规则查询。
- AC-P0-03：审计查询支持事件类型、流程实例、Trace ID、时间范围和分页，结果按发生时间倒序。
- AC-P0-04：核心流程操作写入的事件可通过查询 API 定位，且 API 不返回凭据或敏感变量。
- AC-P0-05：OpenAPI 描述审计查询的请求、分页响应和错误边界；Prometheus 端点仍受平台管理员保护。
