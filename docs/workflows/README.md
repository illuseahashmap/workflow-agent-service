# 历史交付记录

状态：归档

本目录保存按阶段形成的需求、设计、任务、评审和追踪证据，用于还原一次交付在当时的目标与决策，不再承担项目当前状态和下一步计划的维护职责。

维护规则：

- 已结束交付的 `requirements.md`、`design.md`、`tasks.md` 和追踪材料保持历史原貌。
- 当前实现、优先级或技术选型发生变化时，不回写历史快照；在权威文档中记录新状态。
- 历史记录与当前文档冲突时，以[长期设计](../architecture/long-term-design.md)、[下一步计划](../status.md)和[待修复问题](../quality/known-issues.md)为准。
- 新交付只有在需要独立留存验收证据时才新增目录，日常待办不在此处重复维护。
