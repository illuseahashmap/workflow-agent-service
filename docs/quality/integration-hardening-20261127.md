## 真实 Provider 发现与修复

Ark 域名被本机 FlClash Fake-IP 解析到保留地址，生产出站校验正确拒绝。经授权新增该域名的真实 DNS 过滤，保留既有过滤项，不关闭出站校验。

最初原生七场景真实模型批次全部失败，涉及路由阶段误拒绝、工具名称别名及超时。共享路由提示现在包含实际授权工具名称、描述和输入契约，并明确区分“尚未取得证据”与“没有可用授权路径”。一次原生单场景重试已读取实时记录和政策，但仍超过 120 秒 Run 总时限；未延长时限或放松业务断言。

首次图端真实单场景 Run 返回 SUCCEEDED，却将应为 READY_CHECK 的案例推进 MANUAL_REVIEW。实际输出使用自行命名的 action 与自由文本 decision。根因为正常生成未提供输出 Schema，且旧校验器忽略 enum/additionalProperties。修复同时覆盖生成和最终门禁，增加 const、嵌套约束与尾随 JSON 拒绝；不会把已失败记录改写为通过。

下一步必须显式发布 P-17 的必要证据契约，让缺政策/缺实时事实由确定性门禁拒绝；路由提议仅选择可用能力，不能当成业务证据契约。不得为通过验收将“请求了某工具”当成“已经取得证据”，也不得全局强制调用所有选中工具而改变旧版语义。保持现有被冻结的 e1 夹具，新增契约版本后再验收。
