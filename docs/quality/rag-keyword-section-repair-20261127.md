# 关键词与章节证据召回：通用修复及开发集复测

2026-11-27。本轮修改产品检索器，不修改开发题、金标、语料、K 或计分规则；不读取、不修改、不评分 120 条盲测候选。沿用公开 manifest version 3 的 200 条开发题。输入文件 SHA-256 与上次真实运行逐项相等，记录于运行产物的 `provenance-and-comparison.json`。

## 问题与修复

### 1. 问句前缀耗尽词项名额

旧实现从左到右取得最多 16 个唯一词项，中文主要采用二元字组。长问句的介绍、限定语可占满名额，真正的对象可能根本未进入 SQL。只删除评测前缀并不能修复普通用户长问句。

新实现先覆盖完整问句，正常问句保留最多 128 个唯一词项；超过上限时，在完整去重词项序列上等距取样，包含首尾，不再截掉全部后半句。仍有确定性上限，避免按任意输入无限扩展 SQL。超长问题取样仍可能丢失个别词项，这不是完美分词或语义理解；后续可替换分词器，但不依赖题库别名。

### 2. 标题占名额，正文没有跟上

旧关键词路径直接返回高分块。标题含目标名却没有具体规则，因此“命中章节”常常并不等于取得依据。

新增 `SectionKeywordSearch`：标题可作为定位种子，但普通文本路径返回同节正文，纯 ATX Markdown 标题不占最终名额。没有标题的块保持原来的独立文本语义。特别保留旧版“标题和正文混在一块”的内容，不能因以 `#` 开头就整个剔除。金额表、适用范围比较的既有结构化路径保持原规则，表头可能是必要证据，不一刀切删除。

### 3. 关键词只在一段，限制条件在另一段

旧路径缺少通用的章节上下文扩展，往往只能取到结论或条件中的一段。新路径从相关种子找最近的章节标题，并把下一标题作为边界；允许同节少量正文参与最终竞争，正文自身命中程度优先，同节后续块逐步降权，避免单个章节无界占满结果。

所有种子、标题、边界和补充正文都来自同一个 `eligible` 集合，继续检查租户、授权 source、启停、文档状态和活动/冻结索引版本；扩展连接同时限定文档与索引，不按全库 ordinal 随意拼接。候选种子限制在 32–200，单节最多取 4 个正文块，最终仍遵守调用方 K。跨文档主要依靠各文档独立命中进入候选，本轮没有实现对任意引用文本的跨文档递归跟随。

重复公共声明也会干扰排序，因此按当前可见候选中相同内容指纹的出现次数进行平方根降权。这个规则针对重复内容本身，不识别题库中的声明句、文档编号或业务术语。它改变排序，不改变原件和引用。

## 验证与兼容

新增机制测试使用光谱采集、温场记录等独立小语料，验证标题找到正文、两个来源共享名额、章节边界、私有 source、其他租户和 K 限制；不是读取 400 题再断言答案。词项测试覆盖长前缀、问句尾部和超限全域取样。

既有回归涵盖冻结索引与撤权、多个来源稳定排序、采购 Markdown 基线、条件金额证据以及双侧适用范围比较。9 项单元/数据库回归通过，真实开发集运行 1 项通过，共 10 项、零失败、零跳过。受影响四个 Java 文件通过项目 Checkstyle；`git diff --check` 通过。

接口、存储表、原件和索引格式未改变，不需要数据库迁移或重建既有索引。新排序策略会改变重新执行的检索结果；旧运行日志仍保留，不把旧结果解释成新算法的结果。主会话业务数据库和构建目录未使用：测试在工作区外副本与 Testcontainers 临时数据库运行。

## 保留的失败与风险

Top 10 有 70 题从不完整变为完整、3 题从完整变为不完整，净增 67；不是每一题都变好。三个退步案例涉及差旅保险、恢复与关闭、交付版本与部署核验，详见机器比较文件；没有按其 caseId 加优先级或补金标路由。全 24 条未达完整正文覆盖的题保留在 `failures.jsonl`。

剩余问题包括同义表达、不同文档依据之间词面关联弱、有限结果名额内的证据平衡。唯一 EMPTY 还暴露了既有 `PolicyComparison` 将“物资借用”中的“借用”误识别成制度套用比较：它属于独立的语义路由误判，本轮没有为了消灭这道失败题增加词库排除项。不能将全部剩余失败都归因于词项截断。

目前章节扩展针对单行 ATX Markdown 标题，受 4 块/节限制，不代表任意长章节、复杂层级、PDF 或所有 Office 结构已解决。语义改进与大规模性能还需要独立通用数据验证；没有使用盲测来选择参数。
